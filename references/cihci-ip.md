# CIHCI 醬 IP

## 角色定義

CIHCI 醬是 CIHCI Lab 配圖的固定視覺 IP。

每張圖都要出現 CIHCI 醬。它不是吉祥物，不是貼紙，不是可愛裝飾，而是正在認真參與系統運轉的荒誕工作者。

角色原型是實驗室 logo：`assets/ip/cihci.png`（無字版，畫角色時看這張）與 `assets/ip/cihcilab.png`（含 CIHCI LAB 字樣，只用於品牌標示，不要畫進插圖）。

## 外形

身體＝實驗室 logo 的幾何形，其餘擬人特徵沿用手繪小怪物的作法。

### 身體（logo 幾何形）

- 兩條半透明色帶交疊成 X 形／蝴蝶形：一條青藍色帶由左上斜向右下，一條桃紅色帶由右上斜向左下。
- 兩條色帶重疊處透出綠色，位置偏右下。
- 三個深藍色圓角小方塊落在色帶末端與交會處，像關節或扣件。
- 色帶邊緣是手繪的，略微抖動、轉角不完全對齊，不是精準向量圖形。
- **描邊**：色帶是純色塊，邊緣加黑色輪廓線。
- 整體剪影要能一眼認出是那個 X 形，不要畫成規則的蝴蝶結或風車。

### 擬人特徵（沿用原設計）

- 眼睛：兩顆白色圓點緊鄰，各含一顆黑點瞳孔，落在身體中央、色帶交會處附近。小，約身體寬度的四分之一。
- 視線：沒有嘴巴也沒有眉毛，瞳孔方向是唯一的表情。瞳孔要偏離中心、指向牠正在看的東西。
- 手臂：從身體中段側緣伸出的細黑線，自然弧度，不要畫肘關節。
- 手：極小的簡筆末端——三四根短線像爪，或一小團握住東西。不是完整的手掌，小到像線末端的變化。
- 腿：短、細，膝蓋往外折一下，腳只是兩道小斜線，沒有腳掌。站姿是穩的三角形。
- 表情空、呆、冷靜、認真。沒有嘴巴、沒有眉毛、沒有腮紅。

描述手腳時字要少。寫得越細，模型就把牠畫得越大，場景就越被擠掉——手指、肘關節、腳掌這些細節根本畫不進一個小角色裡，模型為了滿足描述只好放大牠。這是實測出來的失敗模式，不是理論。

## 三個識別要件

CIHCI 醬可以變形——壓扁成漏斗、盒子、影子、洞口、機器內部的一塊色塊都可以——但下面三件事不能丟：

1. 兩條色帶交疊成 X 形。
2. 重疊處是綠色。
3. 三個深藍圓角方塊。

三件事都在，怎麼變形都還是 CIHCI 醬。丟掉任何一件，就是別的角色了。

## 顏色

| 部位 | 色碼 | 說明 |
| :--- | :--- | :--- |
| 青藍色帶 | `#2EB1FF` | 左上到右下那條 |
| 桃紅色帶 | `#FF63B2` | 右上到左下那條 |
| 綠色重疊區 | `#36B729` | 兩帶交會處 |
| 深藍方塊 | `#015DA0` | 三個圓角小方塊 |
| 眼睛 | 白、黑 | 兩顆圓點中間黑點 |
| 手腳、輪廓 | 黑 | 細線 |

CIHCI 醬是整張圖唯一的彩色物件。其他所有東西都是黑色手繪線稿，詳見 `style-dna.md`。

## 性格

- 很認真，但做的事有點荒誕。
- 像一個低調的系統操作員。
- 冷幽默，不賣萌。
- 有點笨拙，但不蠢。
- 像在白板草圖裡真的負責某個工作。

## 常見職責

讓 CIHCI 醬承擔核心動作：

- 搬運素材。
- 拉線匯聚資訊來源。
- 卡在斷點裡。
- 在機器裡操作「判斷」桿。
- 變成篩選漏斗。
- 把一份東西切成好幾份。
- 蓋章、封箱、貼標。
- 牽著一條承接路徑走。
- 舉警告牌看坑。
- 從洞裡伸手但接不住東西。
- 在旁邊搬磚、搭橋、開門、分揀、記錄。
- 學術圖解模式時：站在方法架構的某一層裡動手調整、在資料流的閘門上守著、把實驗條件一組一組放進裝置。

## 禁止

- 不要把 CIHCI 醬畫成過度可愛的吉祥物。
- 不要畫成兒童卡通角色。
- 不要給它複雜服裝、表情包、閃亮眼睛。
- 不要讓它只是站在角落裡看。
- 不要讓它搶走結構表達。
- 不要畫得太商業、太圓潤、太精緻。
- 不要給牠完整的手掌、明顯的肘關節或腳掌。
- 不要為了把手腳畫清楚而放大牠，讓牠蓋過場景。
- 不要只描一半的邊——描邊要整圈完整，缺一段會讓身體看起來像沒畫完。
- 不要把色帶畫成乾淨的向量圖形或加上漸層、光暈、陰影。
- 不要在插圖裡出現「CIHCI LAB」字樣（含字版只用於品牌標示）。
- 不要因為身體是彩色的，就順手把畫面其他物件也上色。

## 判斷標準

如果把 CIHCI 醬拿掉，圖的核心隱喻還能完全成立，代表它太裝飾了；要重寫提示詞，讓它成為動作主體。
