# QA 檢查表

## 必過項

- 比例符合用途（見 `style-dna.md` 的比例對照表）。
- 背景是乾淨白底。
- CIHCI 醬有出現。
- CIHCI 醬的三個識別要件都在：兩條色帶交疊成 X、重疊處是綠色、三個深藍圓角方塊。
- CIHCI 醬承擔核心動作，不只是裝飾。
- CIHCI 醬是畫面唯一的彩色物件，其他物件都是黑色線稿。
- 圖上所有中文都是正體字，沒有簡體字。
- 沒有出現「CIHCI LAB」字樣。
- 這張圖的隱喻是新的，沒有跟同一批其他圖撞。
- 畫面荒誕、有創意、有意思。
- 簡潔清爽，主體不超過畫面約 60%。
- 一張圖只講一個核心結構。
- 中文批註少、短、讀得出來。
- 橙色只用於主路徑或箭頭。
- 紅色只用於重點、問題、提醒或結果。
- 深藍 `#015DA0` 只用於補充說明、回饋或系統狀態，且沒有跟 CIHCI 醬的亮青藍混在一起。

## 學術圖解模式加查

- 節點數在 5–7 個以內。
- 所有方框和箭頭都是手繪抖動的，不是規則向量。
- 留白仍有 35% 以上。
- CIHCI 醬在架構裡動手做事，不是站在旁邊當圖例。
- 沒有漸層、光暈、陰影、扁平商業插畫風。

## 失敗訊號

出現以下情況，重生成或局部編輯：

- 左上角有「常見坑 / Workflow / 系統架構圖 / 路線圖」等標題。
- CIHCI 醬變成規則的蝴蝶結、風車或乾淨向量圖形。
- 色帶加了漸層、光暈或陰影。
- 綠色重疊區不見了，或深藍方塊少於三個。
- CIHCI 醬像吉祥物、貼圖或可愛卡通。
- 畫面其他物件也被上了色。
- 批註用了亮青藍，跟 CIHCI 醬撞色。
- 圖上出現簡體字。
- 畫面像 PPT、課程講義、正式流程圖（怪誕正文模式下）。
- 元素太多、箭頭太多、節點太多。
- 文字變成大段解釋。
- 背景有紙紋、陰影、漸層、米色、雜點。
- 真實 UI 擷圖或科技感介面。
- 中文錯字嚴重或批註讀不出來。
- 畫面太死板，沒有荒誕隱喻。
- 跟同一批裡的其他圖用了同一個隱喻或同一個物件。

## 迭代方法

- 太普通：讓 CIHCI 醬成為動作主體，加入一個奇怪但成立的隱喻。
- 太複雜：刪節點，只保留一個動作和 3–5 句短批註。
- 太可愛：強調 deadpan、blank serious expression、not cute、not mascot。
- 太像 PPT：去掉標題、邊框、整齊格線和過多箭頭，改成手繪場景。
- CIHCI 醬走形：用 `prompt-template.md` 的「修 CIHCI 醬走形」局部編輯，不要整張重生成。
- 出現簡體字：用「修簡體字」局部編輯；錯得多就重生成並減少批註數量。
- 跟前一張撞隱喻：保留核心意思，換掉主物件和 CIHCI 醬的動作。

## 交付判斷

高品質的圖應該讓讀者先覺得「有點怪」，然後一秒內看懂結構。

如果第一眼像教學頁，而不是白紙上的荒誕產品草圖，就不合格。
