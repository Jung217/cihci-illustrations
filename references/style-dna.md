# 風格 DNA

## 一句話

純白、極簡、手繪、留白、克制、荒誕、產品草圖感、中文手寫感、結構清楚但不像說明書。

像一個長期做研究、寫程式、帶學生的人，在白紙上隨手畫出來的一張解釋草圖。

## 必須

- 純白背景：不要米色、暖灰、紙張紋理、漸層、陰影、雜點、復古紙感。
- 黑色手繪線稿為主：細線、輕微抖動、不機械、不向量、不厚重描邊。
- CIHCI 醬是畫面唯一的彩色物件（logo 四色），其餘物件、框線、結構一律黑色。
- 大量留白：主體占畫面約 40%–60%，至少 35% 空白，最好有一整塊安靜區域。
- 少量正體中文手寫批註：最多 5–8 處，每處盡量 2–8 個字。
- 一張圖只講一個核心動作、結構、狀態或隱喻。
- 結構要自然表達，不要在圖上寫結構型名稱。

## 顏色

### CIHCI 醬（唯一彩色主體）

| 用途 | 色碼 |
| :--- | :--- |
| 青藍色帶 | `#2EB1FF` |
| 桃紅色帶 | `#FF63B2` |
| 綠色重疊區 | `#36B729` |
| 深藍方塊 | `#015DA0` |

### 畫面其他部分

| 顏色 | 用途 |
| :--- | :--- |
| 黑 | 線稿、框線、結構、主要文字、所有非 CIHCI 醬的物件 |
| 紅 | 重點批註、問題、情緒點、關鍵提醒、結果 |
| 橙 | 主流程、路徑、箭頭、自動化流向、從 A 到 B 的移動關係 |
| 深藍 `#015DA0` | 補充說明、腦內狀態、系統狀態、第二層解釋、AI 或自動化提示 |

批註的藍必須是深藍 `#015DA0`（就是 CIHCI 醬方塊的那個藍），不要用亮青藍——亮青藍是 CIHCI 醬身體的顏色，兩者撞色會讓人分不清哪個是角色、哪個是註解。深藍與亮青藍同色系但明度差夠大，一眼分得開。

深藍批註不是每張都必須用。批註顏色要克制，寧可少不要多。

## 兩種模式

預設是怪誕正文模式。只有在使用者明說要做論文圖、方法架構、實驗設計或投影片圖解時，才切到學術圖解模式。

### 怪誕正文模式（預設）

適用：文章正文配圖、部落格、社群貼文、實驗室對外宣傳。

下面「絕對不要」那一節全部生效，一條都不放寬。

### 學術圖解模式

適用：論文插圖、計畫書圖解、簡報與投影片、Lab meeting。

放寬：

- 允許畫方法架構、系統模組、實驗設計、資料流、處理管線。
- 允許出現模組方框、分支、迴圈箭頭。
- 允許在圖上標英文術語縮寫（例如模組代號、資料集名）。

仍然禁止：

- 彩色漸層、陰影、光暈、發光效果。
- 精緻向量風、扁平商業插畫風。
- 真實 UI 截圖、科技感介面。
- 米色底、紙紋、雜點。
- 密密麻麻的節點——節點上限 5–7 個，超過就拆成兩張。

仍然必須：

- 白底、黑色手繪線稿、大量留白。
- CIHCI 醬在圖裡真的動手做事，不是站在架構圖旁邊當圖例。

## 畫面比例

| 用途 | 比例 |
| :--- | :--- |
| 文章正文配圖 | 16:9 |
| 投影片、簡報 | 16:9 |
| 社群貼文 | 1:1 |
| 論文圖（單欄） | 3:2 |
| 論文圖（雙欄跨欄） | 4:3 或 1:1 |

沒有指定用途時，預設 16:9 橫版。

比例只影響版面配置，不影響上面任何一條風格規則。1:1 的社群貼文尤其要注意別把畫面填滿——正方形更容易顯得擠，留白要求不變。

## 絕對不要

- 不要商業插畫。
- 不要 PPT 資訊圖。
- 不要正式流程圖。（學術圖解模式放寬）
- 不要課程講義。
- 不要可愛卡通海報。
- 不要兒童插畫。
- 不要複雜架構圖。（學術圖解模式放寬）
- 不要精緻扁平插畫。
- 不要科技感 UI。
- 不要真實 App 擷圖。
- 不要複雜背景、漸層、陰影、紋理。
- 不要把每個節點都解釋清楚。
- 不要在左上角寫「Workflow 流程圖 / 系統架構圖 / 常見坑 / 路線圖」等型別標題。
- 不要因為 CIHCI 醬是彩色的，就把畫面其他物件也上色。

## 審美方向

要荒誕、有創意、有意思、簡潔清爽、天馬行空。

不要可愛、幼稚、太複雜、死板。
